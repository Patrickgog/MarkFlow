📖 Manual de Usuario y Documentación Técnica Integral

MarkFlow Office · Guía Completa

1. Arquitectura de Documento Único y Pestañas de Formato

En MarkFlow Office, el contenido del documento se centraliza en la pestaña Docs (editor tipográfico y Markdown). Las pestañas de salida (Word, HTML, PDF y Excel) reflejan en tiempo real ese mismo contenido, aplicando las opciones específicas seleccionadas en su respectiva barra lateral deslizable.

2. Pestaña Word: Temas Nativos vs. Personalizados

Al trabajar en la pestaña Word (.docx):

  • Temas Nativos (tema1, tema2, tema3): Cuentan con diseño y paleta cromática inmutable protegida. La barra lateral muestra el aviso de Tema Nativo Inmutable para evitar alteraciones visuales accidentales.
  • Tema Personalizado (🎨): Desbloquea la selección de paletas suaves ejecutivas o paletas totalmente a medida con selectores de color RGB para títulos H1/H2, cabeceras de tabla, filas alternas y bordes.
  • Round-Trip .docx: Permite importar documentos .docx existentes, extraer su texto limpio a Markdown, descargarlo como archivo .md o transferirlo directamente al editor Docs para continuar trabajando.

3. Pestañas PDF, HTML y Tablas Excel

📕 Visor PDF en Vivo

Compila el documento con Chromium Headless local y CSS Paged Media. Permite maquetación de dos columnas, notas al pie, numeración y running header.

🌐 HTML Autónomo

Entrega un archivo web 100% independiente con estilos incrustados y fórmulas matemáticas renderizadas listas para compartir.

📊 Tablas Excel

Visualiza las tablas en formato hoja de cálculo, descarga libros .xlsx estilizados y copia al portapapeles con formato nativo para pegar en hojas de cálculo.

4. Placeholders Dinámicos y Generación por Lotes

La pestaña Plantillas permite convertir cualquier documento Markdown en una plantilla paramétrica con campos {{variable}}, mapear datos desde matrices tabulares y generar paquetes documentales completos con un solo clic.

5. Entregables y Auditoría

Cada archivo exportado (.docx, .pdf, .html, .xlsx, .md) se registra en la pestaña Entregables con su hora de generación, tamaño y acceso directo para descarga o visualización.
