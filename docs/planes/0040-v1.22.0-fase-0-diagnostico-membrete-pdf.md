## 3. Conclusión y Decisión Técnica de la Fase 0
- **Ambas plantillas son Tipo 1.**
- No se requiere la Opción B ni añadir librerías como `pypdf` (además `pymupdf` ya forma parte del núcleo).
- Toda la generación se realizará de forma **100% nativa, offline y sin dependencias externas**, aprovechando Chromium headless (`--headless --print-to-pdf`) y `pymupdf` para la numeración anti-colisión.
