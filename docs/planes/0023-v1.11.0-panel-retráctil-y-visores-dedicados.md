# Plan 0023 — Corrección de Carga .MD, Panel Lateral Retráctil y Visores Dedicados (Word, PDF, HTML y Excel)

## 1. Identificación y Objetivos
- **Versión Objetivo:** v1.11.0 (Incremento tipo MINOR).
- **Módulos Afectados:**
  - `templates/office.html` (riel de navegación, barra docs, nuevo panel lateral retráctil, nuevas secciones HTML y Tablas Excel).
  - `templates/index.html` (sincronización de componentes de carga de archivos).
  - `static/css/office.css` y `static/css/components.css` (estilos de panel lateral retráctil, indicador activo de modo fuente, menú superior de Docs ampliado, cuadrícula mallada estilo hoja de cálculo Excel, visor HTML dedicado).
  - `static/js/office.js` (orquestación de apps, panel lateral retráctil, extracción de tablas, sincronización con Docs, eliminación de PDFs).
  - `static/js/editor_docs.js` (comando e inserción de notas `data-bd="nota"`).
  - `static/js/visor_pdf.js` (botón de descarga directa y botón de eliminación por ítem y global).
  - `static/js/plantillas.js` (robustecimiento de lectura UTF-8 de archivos `.md` y refresco automático de vistas).
  - `app/rutas/office.py` (endpoints para eliminación de PDFs `DELETE /pdfs/archivo/{ruta}` y exportación de tablas a Excel `.xlsx`).
  - `pruebas/test_v1_11_0.py` (batería de pruebas unitarias y de integración).

---

## 2. Tareas de Implementación

### Fase 1: Corrección de Carga de Archivos `.md` (Requisito 1)
1. **Plantillas y Placeholders:**
   - Asegurar que `<input type="file" id="entrada-plantilla-md">` y `<input type="file" id="entrada-usar-md">` acepten explícitamente `.md, .markdown, .txt, text/markdown, text/plain`.
   - Modificar `cargarArchivoOrigen` y `cargarPlantillaMd` en `static/js/plantillas.js` para asegurar decodificación estricta UTF-8, inyección inmediata en textarea, sincronización en editor WYSIWYG de tags e invocación de `actualizarRenderHtmlResultado(texto)` para que el renderizado izquierdo se actualice instantáneamente sin excepciones.
2. **Pestaña Documentos:**
   - Habilitar importador directo de archivos Markdown (`btn-importar-md` / `input-md-importar`) en `#panel-documentos` para permitir subir documentos `.md` directamente al almacén local FTS5.

### Fase 2: Indicador Visual de Modo Fuente, Menú Superior y Botón de Notas (Requisito 2)
1. **Indicador de Modo Fuente:**
   - Programar en CSS (`static/css/office.css`) la clase `#btn-modo-fuente.activo` con color dinámico (verde esmeralda o azul activo) con alto contraste tanto en modo claro como en modo oscuro.
   - Actualizar el texto a `</> Fuente Activo` cuando esté activado.
2. **Visibilidad del Menú Superior de Docs:**
   - Incrementar dimensiones mínimas de los botones `.bd-btn` a 34px × 34px, fuentes más legibles (0.95rem), espaciado mejorado y bordes sutiles.
3. **Comando de Embeber Notas (`> [!NOTE]` / `> **Nota:**`):**
   - Incorporar en `#barra-docs` el botón `<button type="button" data-bd="nota" class="bd-btn bd-nota" title="Insertar Nota / Aclaración (> [!NOTE])">📝 Nota</button>`.
   - En `static/js/editor_docs.js` y `static/js/office.js`, habilitar el comando tanto para modo visual (envolviendo o insertando bloque callout) como para modo código (prefijando la línea/selección con `> [!NOTE]\n> `).

### Fase 3: Panel Lateral Retráctil de Conversión Completa en Docs (Requisito 3)
1. **Estructura y Animación del Panel:**
   - Crear el panel vertical retráctil `<aside id="panel-lateral-exportar" class="panel-lateral-conversion">` anclado a la derecha del editor Docs, con botón flotante / botón en barra `#btn-abrir-panel-conversion`.
   - Soporte de apertura/cierre fluido con transición CSS y botón de cierre `✕`.
2. **Opciones Avanzadas:**
   - Selección de formatos: Word (`.docx`), PDF (`.pdf`), HTML (`.html`), Markdown (`.md`), Tablas Excel (`.xlsx`).
   - Selección de paleta de colores y temas para cada motor.
3. **Centralización y Corrección de "Exportar a Word":**
   - Implementar función universal `obtenerMarkdownActual()` que sincronice el texto desde ProseMirror (`window.MFOEditor.getTexto()`) o `#editor-markdown`.
   - Generación directa con reporte de estado y botones para descargar de inmediato o redirigir a la pestaña dedicada correspondiente.

### Fase 4: Vistas y Pestañas Dedicadas por Formato (Requisito 4)
1. **Pestaña Word (`#panel-word`):**
   - Actualizar para que muestre la estructura y metadatos del documento Word a generar y active el botón de descarga directa sin depender de estados ambiguos.
2. **Pestaña PDF (`#panel-pdf`):**
   - Incorporar botón de **Descarga Directa** en la barra del visor.
   - Implementar endpoint `DELETE /api/office/pdfs/archivo/{ruta_relativa:path}` en `app/rutas/office.py`.
   - Incorporar botón de **Eliminar PDF** tanto en la barra del visor como en cada tarjeta de la biblioteca de PDFs con confirmación.
3. **Pestaña HTML (`#panel-html` - NUEVO):**
   - Añadir botón en el riel de navegación `data-app="html"` con icono `🌐`.
   - Panel con visor `<iframe>` sandbox de alta fidelidad, selector de temas, botón de descarga directa (`⬇ Descargar HTML`), botón de apertura en nueva pestaña (`↗ Abrir`) y refresco en vivo desde Docs.
4. **Pestaña Excel / Tablas Tabulares (`#panel-tablas` - NUEVO):**
   - Añadir botón en el riel de navegación `data-app="tablas"` con icono `📊`.
   - Parser de tablas Markdown para extraer automáticamente todas las tablas del documento activo.
   - Interfaz interactiva estilo hoja de cálculo de Excel (filas numeradas 1, 2, 3... y columnas con letras A, B, C...).
   - Botón flotante **"Copiar Tabla"** que copia al portapapeles en formato TSV tabulado listo para pegar en Excel.
   - Endpoint `POST /api/office/exportar-tablas-excel` y botón para descargar el libro `.xlsx` con todas las tablas.

## 3. Criterios de Aceptación
- [ ] La carga de archivos `.md` en la suite de plantillas funciona inmediatamente tanto por explorador como por drag & drop, renderizando el texto en el editor y actualizando el visor HTML izquierdo.
- [ ] El botón de modo fuente en Docs cambia dinámicamente de color a verde/azul activo con excelente contraste en modo claro y oscuro.
- [ ] La barra superior de iconos de Docs es más espaciosa y visible, y el botón de "Nota" inserta o envuelve el párrafo en un bloque de nota tanto en visual como en código.
- [ ] El panel lateral retráctil de conversión en Docs se abre fluidamente a la derecha, ofrece todas las opciones de conversión y exporta a Word/PDF/HTML/Excel sin archivos en blanco.
- [ ] La pestaña PDF permite descargar y eliminar archivos PDF con confirmación.
- [ ] La nueva pestaña HTML permite visualizar y descargar el documento HTML compilado.
- [ ] La nueva pestaña Tablas estilo Excel muestra una cuadrícula mallada, permite copiar los datos con un clic para pegar en Excel y descargarlos en `.xlsx`.
- [ ] La suite pasa el 100% de las pruebas automatizadas de pytest y mantiene higiene absoluta de raíz.
