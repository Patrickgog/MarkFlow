## 1. Objetivo
Implementar el motor de inspección geométrica de documentos Word (`motor/membrete.py`) para analizar hojas de membrete `.docx` sin abrirlas en Word. El motor examina cabeceras, pies y cuerpo, localizando imágenes (ancladas o en línea), sus dimensiones, posiciones y envolturas, para determinar la `zona_sugerida_cm` (top, bottom, left, right) que garantice que el contenido Markdown de Docs no tape los logotipos ni las franjas de membrete. Asimismo, soportar la persistencia de zonas manuales mediante archivos `Nombre.zona.json`.

---

## 2. Reglas Técnicas y Fórmulas
1. **Factores de Conversión:**
   - $1\text{ cm} = 360\,000\text{ EMU}$
   - $1\text{ pt} = 20\text{ dxa} = 12\,700\text{ EMU}$
   - $1\text{ cm} = 566.929\text{ dxa}$ ($1\text{ in} = 2.54\text{ cm} = 1440\text{ dxa}$)
2. **Dimensiones de Página Estándar (A4):**
   - $w = 21.0\text{ cm}$ ($11906\text{ dxa}$), $h = 29.7\text{ cm}$ ($16838\text{ dxa}$)
3. **Criterios para `zona_sugerida_cm`:**
   - **Archivo `Nombre.zona.json`:** Si existe junto a la plantilla, se adoptan directamente sus valores `{ "top": float, "bottom": float, "left": float, "right": float }`.
   - **Imagen de página completa (`alto_cm > 27.0`):** Se adoptan los márgenes del `sectPr` (`pgMar`).
   - **Banda superior (header / top):** Si hay una imagen en el header o anclada en la parte superior, la zona top sugerida se calcula como:
     $$\text{top} = \text{borde\_inferior\_imagen\_cm} + 0.5\text{ cm (margen de seguridad)}$$
   - **Banda inferior (footer / bottom):** Si hay imagen en el pie o anclada cerca del fondo, la zona bottom sugerida garantiza que el texto no toque la imagen:
     $$\text{bottom} = (h - \text{borde\_superior\_imagen\_cm}) + 0.5\text{ cm}$$
   - **Márgenes laterales:** Se conservan los márgenes del `sectPr` (o mínimo $2.5\text{ cm}$).
   - **Imagen en el cuerpo:** Si una imagen se detecta en el cuerpo principal (`word/document.xml`), se emite advertencia explícita y se programa su marcado como `behindDoc = 1` para que el texto fluya al frente.
4. **Ancho Útil (`util_dxa`):**
   - Calculado dinámicamente: $\text{ancho\_pagina} - \text{margen\_izq} - \text{margen\_der}$.
