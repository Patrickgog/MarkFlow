## 1. Objetivo
Implementar la función `extraer_membrete_pdf(ruta_docx)` que:
1. Inspecciona el archivo `.docx` de membrete sin requerir Word instalado.
2. Identifica si el membrete es de **página completa** (`HojaPlantilla2.docx`) o de **bandas superior/inferior** (`HojaPlantilla1.docx`).
3. Extrae las imágenes raster (`PNG`, `JPG`) y las convierte a Data URI Base64 (`data:image/png;base64,...`).
4. Determina las coordenadas y cotas métricas en centímetros (`ancho_cm`, `alto_cm`, `top_cm`, `bottom_cm`, `left_cm`).
5. Dispone de un sistema de caché en memoria/disco basado en el mtime del archivo para evitar re-extracciones en llamadas sucesivas.
6. Maneja de forma segura documentos sin imagen retornando lista vacía sin arrojar excepciones.
