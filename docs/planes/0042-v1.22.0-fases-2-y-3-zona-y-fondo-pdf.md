## 1. Fase 2: Zona de Escritura y Márgenes @page
- En `motor/a_pdf.py` (`_generar_html_impresion` y `a_pdf`):
  - Añadir soporte para recibir `plantilla_word` o `zona_cm`.
  - Si hay membrete o zona_cm:
    - Inyectar en `@page`:
      `margin: {top}cm {right}cm {bottom}cm {left}cm !important;`
    - Recalcular ancho útil:
      `ancho_util_cm = 21.0 - left - right`
  - Si no hay membrete:
    - Conservar exactamente el margen actual:
      `margin: 25.4mm` (APA) o `margin: 20mm 20mm 25mm 20mm` (estándar).

---

## 2. Fase 3: Inserción del Membrete como Fondo Fijo (Opción A)
- Si hay membrete:
  - Invocar `extraer_membrete_pdf(plantilla_word)`.
  - Para cada elemento extraído, generar una capa fija con `z-index: -100` y `pointer-events: none`:
    - Caso `fondo_completo`:
      ```html
      <div class="mfo-membrete-fondo" style="position: fixed; left: 0; top: 0; width: 21cm; height: 29.7cm; z-index: -100; pointer-events: none;">
        <img src="{data_uri}" style="width: 21cm; height: 29.7cm; object-fit: fill; display: block;" />
      </div>
      ```
    - Caso `cabecera`:
      ```html
      <div class="mfo-membrete-cabecera" style="position: fixed; left: 0; top: 0; width: 21cm; height: {alto_cm}cm; z-index: -100; pointer-events: none;">
        <img src="{data_uri}" style="width: 100%; height: 100%; object-fit: contain; display: block;" />
      </div>
      ```
    - Caso `pie`:
      ```html
      <div class="mfo-membrete-pie" style="position: fixed; left: 0; bottom: 0; width: 21cm; height: {alto_cm}cm; z-index: -100; pointer-events: none;">
        <img src="{data_uri}" style="width: 100%; height: 100%; object-fit: contain; display: block;" />
      </div>
      ```
  - En Chromium (`--headless --print-to-pdf`), los elementos con `position: fixed` se imprimen automáticamente en cada una de las páginas generadas sin excepción.
