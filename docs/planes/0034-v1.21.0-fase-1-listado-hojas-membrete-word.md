# Plan 0034 — Fase 1: Carpeta y Listado Seguro de Plantillas de Hoja de Membrete Word

**Versión objetivo:** v1.21.0 (en curso por fases)  
**Ruta del plan:** `docs/planes/0034-v1.21.0-fase-1-listado-hojas-membrete-word.md`  
**Referencia:** `docs/mejoras/mejoras_app_13_word.md`

---

## 1. Objetivo
Implementar la infraestructura de descubrimiento, validación de seguridad y consumo frontend del catálogo de hojas de membrete Word (`.docx`) almacenadas en `storage/plantillas_word/`, de modo que tanto el backend como el frontend conozcan en tiempo real las hojas disponibles sin necesidad de reiniciar la aplicación.

---

## 2. Decisiones de Diseño Aprobadas (Fase 1 y posteriores)
1. **Contenido exclusivo de Docs:** No se procesan placeholders de oficios ni campos artificiales; únicamente el cuerpo Markdown de Docs se transfiere a la hoja.
2. **Zona de escritura parametrizada:** Controles visuales en cm para encabezado (top), pie (bottom), margen izquierdo (left) y margen derecho (right).
3. **Casilla de pie de página / numeración:** Checkbox que decide si se añade la numeración o pie.
4. **Manejo de imagen en el cuerpo:** Si una plantilla posee imagen en el cuerpo, se ubicará detrás del texto (`behindDoc = 1`) y el informe se escribirá al frente.

---

## 3. Cambios Técnicos de la Fase 1

### 3.1 Backend (`app/rutas/office.py`)
- Definición de la constante `DIR_PLANTILLAS_WORD = RAIZ / "storage" / "plantillas_word"`.
- Función auxiliar segura `validar_plantilla_word_segura(nombre_archivo: str) -> Path | None` que valida que:
  - No esté vacío.
  - Tenga extensión `.docx`.
  - Resuelva dentro de `DIR_PLANTILLAS_WORD` con `resolve()` y `relative_to()` (prevención estricta de Path Traversal `../`).
  - El archivo exista físicamente en disco.
- Nuevo endpoint: `GET /api/office/plantillas-word`:
  - Escanea `DIR_PLANTILLAS_WORD` en cada petición (`*.docx`).
  - Retorna `{"ok": True, "datos": {"plantillas": [{"etiqueta": stem, "archivo": name, "tamano": "... KB"}]}}`.
  - Lista vacía si no hay archivos.

### 3.2 Frontend UI (`templates/office.html`)
- En `#sidebar-word-opciones`, creación de una nueva sección dedicada:
  `<details class="sidebar-seccion" data-seccion-id="word-hoja-membrete" open>`
  - Campo selector: `<select id="word-opt-hoja-membrete" class="select-lateral">`
  - Botón: `<button type="button" id="btn-refrescar-plantillas-word" class="btn btn-fantasma chico" title="Actualizar lista de hojas de membrete">🔄 Actualizar hojas</button>`
  - Primera opción fija: `"Sin plantilla (predeterminada)"` con valor `""`.

### 3.3 Frontend Lógica (`static/js/office.js`)
- Función `cargarPlantillasWordDesdeDisco()`:
  - Realiza `fetch('/api/office/plantillas-word')`.
  - Puebla el select `#word-opt-hoja-membrete` preservando `"Sin plantilla (predeterminada)"`.
  - Enlace al evento click de `#btn-refrescar-plantillas-word`.
  - Invocación en `inicializarBarrasLaterales()`.

---

## 4. Criterios de Aceptación
- [ ] Carpeta vacía: solo aparece la opción "Sin plantilla (predeterminada)".
- [ ] Con hojas en `storage/plantillas_word/`: aparece una opción por cada archivo `.docx` con su nombre amigable y tamaño.
- [ ] Prueba de seguridad: peticiones con `../` o nombres no permitidos son rechazadas con error 400/404.
- [ ] Incorporación dinámica: al añadir una nueva hoja a la carpeta, se refleja al pulsar "Actualizar hojas" sin reiniciar el servidor.
