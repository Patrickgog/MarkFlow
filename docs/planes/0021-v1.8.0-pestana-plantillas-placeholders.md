# Plan 0021: Pestaña "Plantillas" para MarkFlow Office (Placeholders Dinámicos)

Este plan define la arquitectura, diseño e implementación de la nueva pestaña **"Plantillas"** (Finalidad A: Crear plantilla; Finalidad B: Usar plantilla con Excel/JSON) preservando al 100% las pestañas y el pipeline de conversión existentes.

---

## 1. Identificación y Objetivos

- **Versión actual:** v1.7.0
- **Versión objetivo:** v1.8.0 (Incremento tipo MINOR según SemVer).
- **Objetivo principal:**
  Permitir a ingenieros y consultores generar memorias técnicas y documentos repetitivos a partir de plantillas Markdown con placeholders con nombre (`{{nombre_dato}}`), asociadas a datos en hojas de cálculo Excel (`.xlsx`) y diccionarios estructurados (`.json`), integrándose transparentemente con los motores existentes de exportación a HTML, Word, PDF y Markdown.

---

## 2. Alcance (Fase 1)

1. **Nueva pestaña principal:** `🧩 Plantillas` con sub-pestañas:
   - `✏️ Crear plantilla` (Finalidad A)
   - `📄 Usar plantilla` (Finalidad B)
2. **Motor de Plantillas (`motor/plantillas.py`):**
   - Detección heurística de candidatos con nivel de confianza (alta, media, baja) protegiendo fórmulas matemáticas y bloques de código.
   - Normalización de nombres de placeholders: minúsculas, dígitos, guion bajo, sin tildes ni espacios, máximo 60 caracteres.
   - Generación y lectura de libro Excel `.xlsx` estructurado (hoja "Datos", columna A `placeholder`, columnas B+ proyectos).
   - Generación y lectura de especificación `.json`.
   - Motor de validación (completos, vacíos, tipo incorrecto, sobrantes).
   - Motor de sustitución y formateo con marcado en rojo de campos no provistos (`[nombre]`).
3. **Servicios API (`app/rutas/plantillas.py`):**
   - Endpoints para análisis preliminar, generación de plantilla con dataset Excel/JSON, validación de datos vs. plantilla, y ensamblado de documentos finales.
4. **Interfaz Web (`templates/index.html`, `static/css/`, `static/js/`):**
   - Componentes de zona de arrastre `.zona-suelta`, tabla de candidatos interactiva, editor con chip visual `[nombre]`, selector de proyecto y panel de validación visual con contadores semánticos.

---

## 3. Criterios de Aceptación

- [x] Instalación y registro de `openpyxl>=3.1.2` en `requirements.txt`.
- [x] Motor puro en `motor/plantillas.py` sin efectos secundarios, 100% testeable por CLI / pytest.
- [x] No alteración de la lógica ni estilos existentes en "Tus datos", "Salida" y "Manual de Usuario".
- [x] Fórmulas matemáticas (`$$ ... $$`, `\( ... \)`) y bloques de código (```` ``` ````) inmunes a sustituciones.
- [x] Archivo Excel generado compatible con Microsoft Excel y LibreOffice Calc.
- [x] Suite completa de pruebas verdes en `pytest pruebas/`.
- [x] Incremento de versión semántica en `app/version.py` a `v1.8.0`.
