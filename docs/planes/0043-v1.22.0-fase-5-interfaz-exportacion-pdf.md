## 2. Lógica en `static/js/office.js`
- Poblar `#pdf-opt-hoja-membrete` con las plantillas devueltas por `GET /api/office/plantillas-word`.
- Al cambiar de hoja en PDF, consultar `/analisis` y mostrar/ocultar `#contenedor-zona-membrete-pdf`.
- En `ejecutarExportarPdf()` y en `refrescarVisorPdfEnVivo()` incluir en el payload:
  `plantilla_word`, `zona_top`, `zona_bottom`, `zona_left`, `zona_right`.
- Almacenar la selección en `MFORegistro` (`registro_temas.js`) para que se recuerde entre sesiones.

## 3. Backend en `app/rutas/office.py`
- En `ModeloExportarPdf`:
  - `plantilla_word: str = ""`
  - `zona_top: float | None = None`
  - `zona_bottom: float | None = None`
  - `zona_left: float | None = None`
  - `zona_right: float | None = None`
  - `alineacion_num: str = "derecha"`
  - `posicion_numero: str = "derecha"`
- En `endpoint_exportar_pdf`:
  - Validar `plantilla_word` si no está vacía usando `validar_plantilla_word_segura()`.
  - Construir dict de zona si se especificaron cotas.
  - Pasar `plantilla_word` y `zona_cm` a `a_pdf()`.
